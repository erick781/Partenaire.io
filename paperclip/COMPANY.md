# Partenaire.io — AI Operations Company

## Mission

Run the financial and operational intelligence layer for Partenaire.io, a Quebec-based growth marketing agency serving 300+ clients across auto dealers, real estate brokers, restaurants, and entrepreneurs.

## Goal

Maximize agency profitability by tracking revenue (MRR/ARR), detecting churn early, flagging overspending, automating invoice oversight, and surfacing actionable financial insights — so Erick and the team can focus on delivering results for clients.

## Org Structure

```
BOARD (Erick — Human Operator)
  │
  CEO Agent — "Le Directeur"
  │   Delegates, escalates, weekly executive summary
  │
  └── CFO Agent — "Le Comptable"
        │   MRR, ARR, P&L, cash flow, overspending, client profitability
        │
        └── Invoicing Analyst Agent
              Invoice status, overdue flags, payment reconciliation
```

## Phase

Phase 1 — CFO Foundation. Future phases will add COO, CRO, and specialist agents.

## Integrations

- Stripe (revenue, payments, invoices)
- PandaDoc (contracts, proposals)
- Supabase (shared data layer with AI CFO Command Center)

## Governance

- Agents can generate reports and flag anomalies autonomously
- Any client-facing communication or financial action requires Board (Erick) approval
- All actions logged to audit trail
